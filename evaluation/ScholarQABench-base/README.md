## 📂 Folder Structure & Description

### `key_ingredients/`
- This folder contains **.txt files**.  
- Each question has **2 corresponding key_ingredient files** (e.g., `1_1.txt`, `1_2.txt`).  
- These are **guidance documents (key ingredients)** extracted from **ScholarQABench**, serving as reference evidence to evaluate answers.

### `qa_nlp.jsonl`
- This file contains **33 NLP-related questions**, filtered from the **100 original questions in ScholarQABench**.  
- **GPT-4o-mini** is used to read the content of each question and classify whether it belongs to the NLP domain.

### `qa_results.jsonl`
- This file contains the **answers generated by our system** for each question in `qa_nlp.jsonl`.  
- Each record includes:  
  - **idx** (question index)  
  - **question**  
  - **response** (system-generated answer)  
  - **elapsed_time_sec** (time taken by the system to answer each question).
