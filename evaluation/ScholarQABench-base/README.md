## 📂 Folder Structure & Description

### `key_ingredients/`
- This folder contains **.txt files**.  
- Each question has **2 corresponding key_ingredient files** (e.g., `1_1.txt`, `1_2.txt`).  
- These are **guidance documents (key ingredients)** extracted from **ScholarQABench**, serving as reference evidence to evaluate answers.

### `qa_nlp.jsonl`
- This file contains **33 NLP-related questions**, filtered from the **100 original questions in ScholarQABench**.  
- **GPT-4o-mini** is used to read the content of each question and classify whether it belongs to the NLP domain.

### `qa_results.jsonl`
- This file contains the **answers generated by our system** for each question in `qa_nlp.jsonl`.  
- Each record includes:  
  - **idx** (question index)  
  - **question**  
  - **response** (system-generated answer)  
  - **elapsed_time_sec** (time taken by the system to answer each question).  
### `qa_evaluations.jsonl`
- This file contains the **evaluation results** for each question in `qa_nlp.jsonl` based on the corresponding `key_ingredients` using gpt-4o .  
- Each record includes:
  - **idx**: Question index.
  - **key_ingredients_id**: Identifier for which key_ingredients file was used (since each question has 2 key_ingredients files).  
  - **rewritten_query**: The query reformulated by GPT-4o-mini.  
  - **system_final_report**: The system-generated final answer.  
  - **evidence**: The content of the key_ingredients file used for evaluation.  
  - **filtered_passages**: Passages retrieved by the system during search, used as evidence context.  
  - **elapsed_time_sec**: Time taken by the system to answer the question.  
  - **evaluation**: JSON object containing the assessment:
    - `answer_evaluation`: Scores and summary comparing the system's final answer to the evidence:
      - `correctness_score` (0–1)
      - `coverage_score` (0–1)
      - `reasoning_score` (0–1)
      - `summary`: Short text comment
    - `passages_evaluation`: Scores and summary comparing the filtered passages to the evidence:
      - `relevance_score` (0–1)
      - `completeness_score` (0–1)
      - `summary`: Short text comment
    - `time_feedback`: Comment on response time (`fast`, `acceptable`, or `slow`)  

- This file is generated by **evaluating the system's answers and filtered passages with GPT-4o-mini**, providing both quantitative scores and qualitative summaries for each question.
